# מערכת ניהול חתימות ציוד - צנחנים

## מה יש בפרויקט
- `db/schema.sql` - מבנה מסד הנתונים (להתקנה חדשה בלבד - **לא** רץ אוטומטית על ה-DB הקיים שלך)
- `db/operations.py` - פעולות ליבה (החתמה/זיכוי/דוחות/מצב מחסן)
- `db/excel_export.py` - יצירת דוח אקסל מלא (6 גיליונות, חייל × ציוד)
- `bot/access.py` - שכבת הרשאות (full/mefaleg/view_only)
- `bot/main.py` - הבוט עצמו עם כל התפריטים
- `scripts/import_soldiers.py` - ייבוא חיילים מקובץ אקסל
- `scripts/migrate_*.py` - מיגרציות (ראה סעיף למטה - **סדר ההרצה חשוב**)
- `.env` - הטוקן שלך (**אל תשתף/תעלה קובץ זה לשום מקום ציבורי**)

## פיצ'רים קיימים
- **החתמה / זיכוי** - כולל ערכות מהירות (קיטים): ציוד רובאי מלא, ציוד לחימה מלא נגב/מאג
- **זיכוי חכם** - מציג רק פריטים שהחייל בפועל מחזיק
- **דוח מחלקה** - שורה לחייל, כל הציוד שלו מופרד בפסיקים
- **דוח חוסרים** - מי עדיין לא חתם על כלום, לפי מחלקה או כלל הפלוגה
- **מצב מחסן** - לכל פריט: סה"כ / מוחתם / נשאר במחסן (מחושב אוטומטית, לא דורש עדכון ידני)
- **ייצוא לאקסל** - קובץ עם גיליון לכל מחלקה, מטריצת חייל × ציוד
- **הוספת חייל** - דרך הבוט, בלי לגעת בקוד
- הבוט מגיב לכל הודעה (גם "היי", לא רק `/start`)
- דוחות פרטיים נשלחים תמיד בהודעה אישית (לא בקבוצה), ומוחקים אוטומטית את הגרסה הקודמת

## הערת אבטחת מידע
דוחות מפורטים (מחלקה, חוסרים, מחסן, אקסל) נשלחים תמיד **בהודעה פרטית** מהבוט למי שביקש,
גם אם ביקשו זאת מתוך הקבוצה - כדי שמידע מפורט (שמות, שיוך למחלקה) לא יוצג לכולם בקבוצה.

## מיגרציות - הרץ בסדר הזה (רק פעם אחת כל אחת, בטוח להריץ שוב בטעות)
אלה מעדכנות את ה-DB הקיים שלך (`db/equipment.db`) בלי למחוק חיילים/היסטוריה:

1. `python scripts/migrate_2026_07_31.py` - שינוי שם חעת -> ח"ע
2. `python scripts/migrate_2026_08_09.py` - עמודת מלאי כולל, עדכון כמויות, ציוד חדש (פאוץ גב, רשת הסוואה וכו'), ציוד גדודי
3. `python scripts/migrate_2026_08_09_merge.py` - איחוד וסט נגב+מאג לפריט אחד, ותוף נגב+מאג לפריט אחד

אם אתה לא בטוח אילו כבר רצו אצלך - אין נזק בהרצה חוזרת, הסקריפטים מזהים את זה ומדלגים.

## איך מריצים על המחשב שלך (התקנה חדשה מאפס)

### שלב 1 - התקנת פייתון
```
python3 --version
```

### שלב 2 - התקנת ספריות
```
pip install -r requirements.txt
```

### שלב 3 - יצירת מסד הנתונים
```
python3 -c "import sqlite3; conn = sqlite3.connect('db/equipment.db'); conn.executescript(open('db/schema.sql', encoding='utf-8').read()); conn.commit()"
```
(בהתקנה חדשה, `schema.sql` כבר כולל את כל הציוד המעודכן - אין צורך בסקריפטי המיגרציה מעל)

### שלב 4 - רישום עצמך כמשתמש מורשה
1. חפש בטלגרם את **@userinfobot** ושלח לו הודעה - הוא יחזיר את ה-ID שלך.
2. הרץ:
```python
import sys; sys.path.insert(0, '.')
from bot import access
access.register_user('ה-ID-שלך', 'השם שלך', 'full')
```

### שלב 5 - ייבוא חיילים מאקסל
```
python scripts/import_soldiers.py "נתיב לקובץ האקסל"
```

### שלב 6 - הרצת הבוט
```
python3 bot/main.py
```
כל עוד החלון הזה פתוח והמחשב דולק - הבוט פעיל.
